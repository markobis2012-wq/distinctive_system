Enterprise ERP System Features

System-Driven Workflow Architecture Specification

System Overview: This document details the exact automated software features and transactional capabilities embedded within the platform. Every phase highlights how the system natively processes data, executes relational database logic, and automates cross-module integration from initial quotation to final inventory deduction.
1

Bidding & Quotation Module

🧩 Interactive Bid Builder & Catalog Integration

The system provides a dynamic quotation interface pulling assembled parent products from a master catalog or defining custom items with integrated margin and cost calculators.

System Action: Persists records into tbl_bids without modifying inventory balances.

📄 Automated Document Generation

The system instantly formats and compiles quotation data into professional, branded PDF documents ready for transmission.

2

Project Conversion & MRF Module

⚡ Automated Project Awarding Engine

Upon status toggling, the system automatically instantiates a new Project record (e.g., 2026-001), transfers quotation items into official project tracking tables, and locks the source bid to preserve financial auditing histories.

📋 Bill of Materials (BOM) to Material Requisition Form (MRF) Exploder

The system reads parent product structures and automatically explodes them into required raw material sub-components, generating an itemized MRF tracking system.

3

Inventory Checking & Procurement Module

📦 Automated Inventory Reconciliation & Allocation

The system evaluates approved MRF requirements against master stock. It isolates available inventory by shifting quantities into a reserved state (reducing qty_available while keeping qty_on_hand intact) and dynamically flags shortages.

📊 Canvassing & Purchase Order (PO) Engine

The system automatically compiles shortaged components into a Procurement Board, aggregates supplier pricing matrixes, highlights optimal costs, and generates formal Purchase Orders linked directly to the target Project ID.

📥 Goods Receipt Note (GRN) & Stock Inflow

Receiving modules process incoming POs, executing automated database transactions that increment master inventory counts while flagging project-specific material arrivals.

4

Production & Return to Stock (RTS) Module

🏭 Production Staging & Pipeline Board

Tracks assembly lifecycles through distinct states (In Production to Ready for Delivery) via an interactive accordion matrix computing real-time aggregate percentage completion bars.

🔄 Return to Stock (RTS) & Ledger Audit Engine

Provides modal interfaces for returning excess factory materials back to warehouse inventory with decimal-precision quantities and operational notes.

System Action: Executes an ACID transaction updating master inventory qty_on_hand while automatically inserting a traceable audit entry into tbl_inventory_added with Supplier ID 0.
5

FSM Dispatch & Unified Logistics Bridge

📅 Field Service Management (FSM) Calendar Scheduling

Enables dispatchers to schedule trucks, assign crews, select time windows, and link staged inventory items directly to formal Job Orders (JO).

🌉 The Single-Row Data Bridge

Transforms scheduling data into shipping records instantly via a backend bridge action.

System Action: Creates a single master delivery record in tbl_delivery, mapping items simultaneously to child component records and parent product matrices to eliminate data drift.
6

Warehouse Printing & Document Engine

📋 Internal Loading List (Pick List) Generator

Renders an optimized internal layout featuring sub-component explosions, item images, and physical square checkboxes designed explicitly for warehouse forklift pick-lists.

📄 External Delivery Receipt (DR) Generator

Renders corporate multi-page templates (supporting A3, Inkjet, and Dot-Matrix hardware profiles) rolling components back up into parent products with formal legal signature blocks.

7

Accomplishment Reporting & Inventory Deduction Module

📸 Digital Accomplishment Portal & Proof of Delivery

Accepts multipart form uploads for signed physical delivery receipt photos, processes crew text notes/exceptions, and appends logs into project accomplishment history fields.

📉 Automated Inventory Subtraction & Status Closure Engine

Closes the project delivery feedback loop completely via automated relational math.

System Action: Shifts Job Order statuses to Completed and executes a backend SQL transaction utilizing MIN() grouping logic over delivery items to calculate assembled parent totals, decrementing staging counts (qty_ready_for_delivery) and incrementing completed metrics (qty_delivered) instantly across project dashboards.
